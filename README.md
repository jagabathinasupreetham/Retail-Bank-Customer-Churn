# Retail Bank Customer Churn Analysis

An end-to-end data analysis project exploring customer churn behavior in retail banking to identify risk factors and support retention strategies.

## Project Workflow
1. **Data Audit & Extraction:** Inspected the raw dataset (`customer churning.csv`) to review structural integrity, record counts, and data types.
2. **Data Cleaning & Exploration (Python):** Used a Jupyter Notebook to validate null values, audit duplicates, format columns, and generate exploratory statistics, exporting a refined dataset (`cleaned_churn_data.csv`).
3. **Data Visualization (Tableau):** Built an interactive dashboard to visualize key performance indicators, regional risk factors, and churn demographics.

## Files in this Repository
- `customer churning.csv`: The original raw dataset.
- `Bank_Churn_EDA.ipynb`: The Jupyter Notebook containing Python code for data inspection, cleaning, and analysis.
- `cleaned_churn_data.csv`: The processed dataset ready for business intelligence tools.
- `dashboard.png`: Screenshot of the final Tableau dashboard.

## Key Insights
- **Baseline Churn:** The overall customer churn rate sits at approximately 20.4%.
- **Geographic Trends:** While France and Spain maintain steady customer retention, Germany shows a noticeably higher proportion of customer churn relative to its user base size.
- **Member Engagement:** Inactive members exhibit a significantly higher dropout rate, highlighting a clear opportunity for targeted re-engagement campaigns.
